# Changes

> Each significant code change should have a directory here:
> `/changes/CHG-001/`
> 
> Contains:
> - `requirement.md` — what was needed
> - `implementation-plan.md` — how it was done
> - `changed-files.json` — list of files modified
> - `decision-log.md` — key decisions made
> - `validation-report.md` — test results, scan results

This directory is created by the Code Understanding flow.
AI agents should read recent changes before modifying code.
