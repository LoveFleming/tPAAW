## Common Issues

### Q: I'm getting Error Code 50001 (INTERNAL_ERROR), what do I do?
This is a generic unhandled error. Check the server logs for a stack trace: `grep "50001" logs/` or look for the error in the terminal output. Restart the service with `pm2 restart paaw` if needed. For detailed debugging, see → `../runbook/50001.md`.

### Q: I'm getting Error Code 50010 (AGENT_TIMEOUT), what do I do?
The agent execution loop exceeded the configured timeout (default 1800s). Retry the request first — it may be transient. If persistent, check LLM API status and consider increasing `maxTimeout` in the agent config. See → `../runbook/50010.md`.

### Q: I'm getting Error Code 50020 (TEST_EXECUTION_FAILED), what do I do?
The Code Health module failed to run tests. Run `npm test` manually to check for configuration issues. Verify test runner installation with `npx jest --version`. See → `../runbook/50020.md`.

### Q: The API returns 500, what should I check?
1. Check the server logs for stack traces: `grep "500" logs/` or look in the terminal output.
2. Verify the backend is running: `curl http://localhost:4000/health`.
3. Check for recent code changes: `git log --oneline -5`.
4. Restart the server: `pm2 restart paaw` or kill and re-run `npm run dev`.

### Q: Changes aren't showing up after restart
- **Frontend:** Clear browser cache (hard refresh: Cmd+Shift+R) or disable cache in DevTools.
- **Backend:** Ensure the build step ran: `npm run build` (if using TypeScript compilation). Check for file watcher issues — restart the dev server with `npm run dev`.
- **Common cause:** The dev server's file watcher may not detect changes in certain directories (e.g., `.paaw/`). Restart the server to force a reload.
