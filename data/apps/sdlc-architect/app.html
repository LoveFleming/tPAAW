🔷 Festify Platform — System Context
📋 Architecture Summary

Festify is a music intelligence platform. The system follows an event-driven architecture with NATS as the central message broker.

  • Festify Server — API gateway handling auth, orchestration, and client requests
  • Inference Server — Model serving with loaded weights for embeddings & predictions
  • NATS — Event bus decoupling real-time data flow
  • Data Collector — Stream processor consuming events and persisting to DB
  • MongoDB — Primary data store for analytics and logs
⚡ Data Flow (live)
User → Festify Festify → NATS NATS → Data Collector Data Collector → MongoDB Festify → Inference
