# Code Review 標準

## 審查重點

1. **架構設計**
   - 程式碼結構是否合理？
   - 是否有過度耦合或分散？
   - 是否遵循 Single Responsibility？

2. **安全性**
   - 是否有 path traversal 風險？
   - 是否有未驗證的使用者輸入？
   - 敏感資料是否妥善處理？

3. **效能**
   - 是否有不必要的迴圈或重複計算？
   - I/O 操作是否有 batch 或 cache？
   - 大型資料處理是否有效率？

4. **可讀性**
   - 命名是否清楚？
   - 是否有過多的註解？（好的程式碼不需要太多註解）
   - 函數長度是否合理？

5. **錯誤處理**
   - 是否有遺漏的 error handling？
   - error message 是否夠清楚？

## Review 格式

```
## 總評
（一句話總結）

## ✅ 好的部分
- ...

## ⚠️ 需要改進
- ...

## 🔍 詳細問題
### 檔案：xxx.js
- 行號 | 問題描述 | 建議
```
