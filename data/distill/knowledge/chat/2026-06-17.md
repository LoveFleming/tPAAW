- **讀取技巧**：使用 `file_list` 成功時可列出目錄內容；使用 `file_read` 時需要完整的檔案路徑（不含目錄遍歷能力）。

| `file_list` 參數錯誤，無法列出 knowledge 目錄 | 嘗試不同模型（deepseek-v4-flash）、不同工具（`vibe_fs_list`、`fs_tree`），最終在反覆嘗試後成功 |

### 6. 可復用的模式
- **故障排除模式**：當工具失效時，依序嘗試：
  1. 切換模型（glm → deepseek-v4-flash 這類）
  2. 嘗試不同語系（"目錄" vs "檔案"、完整路徑 vs 相對路徑）
  3. 備用工具（`vibe_fs_list` → `file_list` → `file_read`）
  4. 詢問 User 提供替代資訊（貼上內容、用 Vibe 編輯器、用 CLI）
- **知識摘要模式**：對大量文件，要求「全掃一遍給摘要」是高效做法 — Assistant 會依序讀取所有檔案並歸納成結構化報告。
- **Bug 溝通模式**：User 明確指出「路徑對但不是要 call API 嗎？」，引導 Assistant 從「工具沒參數」的觀察深入到「後端程式碼有 Bug」的根本原因。
- **能力邊界確認**：User 連續詢問「可以讀檔案嗎？」「可以寫記憶嗎？」建立對系統能力的完整認知。
