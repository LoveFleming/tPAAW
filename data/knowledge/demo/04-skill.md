# Skill — 最小能力單元

Skill 不是隨機的 LLM 對話，是**有框架的 deterministic script**：

## 固定格式

- **Purpose** — 這個 Skill 做什麼
- **Inputs** — 型別安全的輸入定義
- **Deterministic Script** — 執行步驟
- **Guardrails** — 防呆機制
- **Output Contract** — 保證輸出格式
- **Validation** — 自動驗證

## 為什麼重要？

同樣 input → 永遠同樣 output

這不是 AI 亂寫，是 **AI 在框架內寫**
