# Translation Learning Output

## 1. Original Text
提油救火

## 2. Natural Translation
Adding fuel to the fire — making a bad situation even worse by trying to help.

## 3. Simple Translation
Trying to fix something but making it worse instead.

## 4. Key Vocabulary

| Word / Phrase | Meaning | Example Sentence |
|---|---|---|
| 提油救火 | A Chinese idiom meaning to make things worse by using the wrong method | His sarcastic apology was like 提油救火, only making her angrier. |
| fuel | 燃料、助燃物 | Adding more fuel to the argument only made it worse. |
| make matters worse | 讓事情更糟 | Don't interrupt him now — you'll just make matters worse. |

## 5. Useful Sentence Pattern

**Pattern:**
___ only makes matters worse.

**Example:**
Arguing back only makes matters worse.

## 6. Speaking Version
"You're only making things worse — it's like adding fuel to the fire!"

## 7. Common Mistake

Don't say: "pour oil to save fire" (too literal).
Say: "adding fuel to the fire" or "making a bad situation worse."

## 8. One Sentence to Remember
Trying to calm him down with more criticism is like adding fuel to the fire.
