# 新聞摘要

## Purpose
讀取使用者提供的新聞網站 URL，擷取主要文章內容，整理成結構化的中文摘要報告。支援多種新聞網站格式。

## Inputs
- **新聞網站 URL** (`url`, required)：要擷取的新聞網站網址
- **輸出路徑** (`output_path`, optional)：留空 = 結果直接顯示；填入絕對路徑 = 存成 `.md`

## Deterministic Script

### Tool Access
- `/api/workspace/write` — 將結果寫入指定的 markdown 檔案
- Web fetch 能力 — 擷取網頁內容

### Execution Steps

1. **擷取網頁內容**
   - 使用 web fetch 讀取 `url` 指定的網頁
   - 解析 HTML，擷取主要新聞文章（標題、日期、正文）
   - 如果是首頁（多篇文章），抓取前 5-10 則新聞的標題和連結

2. **整理中文摘要**
   - 將每則新聞翻譯成 2-3 句精煉中文摘要
   - 標註重要程度（🔥 重要 / 📌 關注 / 📰 一般）
   - 加上「為什麼重要」的一句話說明

3. **組裝輸出**
   - 按照 Output Contract 格式組裝完整 markdown
   - 確保所有 section 都有實際內容
   - 日期用今天日期（Asia/Taipei 時區）

4. **輸出結果**
   - **若 `output_path` 有值**：寫入指定路徑，回覆「已產生新聞摘要：{output_path}」
   - **若 `output_path` 為空**：直接顯示完整 markdown

### Business Rules
- 摘要要精煉，不逐字翻譯
- 只報導事實，不加主觀評論
- 不可捏造新聞或連結
- 如果網頁無法讀取，回覆明確錯誤訊息

### Error Handling
1. **網頁讀取失敗**：回覆「無法讀取 {url}，請確認網址是否正確」
2. **輸出路徑無效**：回覆錯誤訊息，不改為直接顯示
3. **無法辨識文章結構**：嘗試擷取純文字內容並整理

## Guardrails
- 只報導事實，不加主觀評論
- 不捏造新聞或連結
- 摘要長度控制在每則 2-3 句

## Output Contract

**輸出模式：both**（有 `output_path` 存檔，沒有則僅顯示）

產出內容為 markdown 格式：

```
# 📰 新聞摘要 — YYYY-MM-DD

**來源**：{url}

---

### 1. 🔥 [新聞標題]
- **來源**：媒體名稱 | YYYY-MM-DD
- **摘要**：2-3 句中文摘要
- **為什麼重要**：一句話說明
- **連結**：<URL>

### 2. 📌 [新聞標題]
...（重複至所有新聞）

---

*Generated by PAAW News Digest*
```

## Validation
- 至少 1 則新聞
- 每則新聞有標題、摘要
- 若有 output_path → 檔案成功寫入
